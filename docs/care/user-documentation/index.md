# **Introduction**

## **What is CARE?**

CARE is an open-source electronic medical record (EMR) and hospital management platform designed to streamline care across outpatient, inpatient, and home care settings. 

## **Who is the guide for?**

It is designed for modularity and interoperability: CARE is fully HL7 FHIR R5 compliant, and uses standard clinical terminologies such as SNOMED CT, LOINC, and UCUM to ensure that data is structured, semantically consistent, and easily shareable across different health systems. 

# **Purpose of This Guide**

This documentation is meant for clinicians, administrators, implementation teams, and technical staff. It serves as a user manual to help you understand, navigate, and use the different modules of CARE, as well as customize or extend them according to your facility's needs. All modules are documented separately—with workflows, configuration, and examples.

# **How to use the documentation?**

**Step 1:** Identify your role (e.g., Reception Staff, Doctor, Nurse, Facility Admin, etc.)

**Step 2:** Refer to the relevant module documentation [(linked in the next section)](#modules-and-user-roles).

**Step 3:** Follow workflows and instructions in that module's guide.

Optional: Note that technical/implementation staff can use module docs for setup, integration, and customization.
