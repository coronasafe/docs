# Infrastructure requirements for Local Deployment

The following table outlines the minimum and recommended infrastructure requirements for a Local Deployment of the CARE HMIS platform.

| Configuration | Nodes | CPU | RAM | Storage |
|---------------|-------|-----|-----|---------|
| Minimum | 2x | 8 Cores per server | 32GB per server | 2TB combined ssd storage |
| Recommended | 2x | 8 Cores per server | 64GB per server | 6TB combined ssd storage |

IAC scripts can be found [here](https://github.com/ohcnetwork/care_local_iac)
